# 朔望月 v0.3 试玩基线

## 程序对照

每套法则用种子 0–999，四种策略重打同一组牌序，共 12,000 场。每个庄家决策使用正式游戏的策略和随机公式。对照策略不主动验牌或使用提示，便于比较行动本身产生的公开证据。

- **有注就弃**：没人下注时过牌，面对下注或加注时弃牌。
- **过牌／跟注**：有人下注就跟注，其余时候过牌。
- **地猴过牌后开注**：面对下注弃牌，地猴先过牌时开注，其余时候过牌。
- **按公开信息估牌**：只读自己的牌、公共牌、地猴明牌和已公开的判例。均匀枚举剩余暗牌及仍相容的法则，把平局计半个胜场。估算摊牌份额达到 70% 时优先挑战，达到 60% 时开注，达到 45% 时跟注。

```powershell
npm run playtest:baseline -- 1000
```

在参数末尾加 `--json` 可输出结构化结果。在本地开发地址用 `?seed=28&rule=large` 可固定牌序和法则。

## 真人首轮

找 4–6 位首次接触游戏的玩家，每人打两场。一场在开发入口打开 `/?seed=28`，这样固定牌序和本场法则，地址中只显示种子。另一场用双击试玩版的随机牌序。为每位玩家开启新的浏览器会话，避免读取上一位的存档。将两种顺序交错分配，让玩家自己选择是否使用新手指导和提示。观察者记录玩家需要口头帮助的位置，以及能否独立完成八手。

1. 玩家有把握时，在「笔记」记录当前判断。后来改变判断时再记一次。
2. 终局下载试玩记录。用「最早区分规则的牌例」对照玩家实际记录判断的时机与当时用过的提示。
3. 询问玩家用了哪条证据，并请对方描述一次因此改变或坚持的下注或挑战。记录这是由规则、牌力还是地猴行动触发的判断。
4. 优先修复重复出现的卡点。先区分缺少公开证据、证据读不懂、看懂后不知怎么下注。每轮只改动一个对应因素，再用相同牌序和新牌序复测。
